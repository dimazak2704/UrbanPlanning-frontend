# UrbanPlan - Система управління містобудуванням

Фронтенд частина системи управління містобудуванням.

## Технології

- **Vue 3** (Composition API, `<script setup>`)
- **Vite** — збірка
- **Vue Router 4** — роутинг
- **Pinia** — управління станом
- **TailwindCSS 3** — стилізація
- **HeadlessUI** + **Heroicons** — UI компоненти
- **Leaflet** — інтерактивні карти
- **Chart.js** — графіка та аналітика

## Запуск проєкту

1. Встановіть залежності:
```bash
npm install
```

2. Запустіть сервер для розробки:
```bash
npm run dev
```

3. Відкрийте браузер за адресою `http://localhost:5173`.

## Бекенд API

Для роботи фронтенду потрібен запущений бекенд (за замовчуванням очікується на `http://localhost:8080/api`).
Ви можете змінити URL бекенду у файлі `.env` (якщо його немає, створіть `.env.local`):

```env
VITE_API_BASE_URL=http://localhost:8080/api
```

### Google Maps Street View
Для роботи інтерактивних панорам Street View потрібен API ключ Google Maps.

1. Створіть проект на https://console.cloud.google.com/
2. Увімкніть Maps Embed API
3. Створіть API key у розділі Credentials
4. Обмежте ключ: HTTP referrers = `http://localhost:*`
5. Додайте ключ у `.env`: `VITE_GOOGLE_MAPS_API_KEY=your_key_here`
6. Перезапустіть dev-сервер (`npm run dev`)

## Структура ролей

- **Гість** (без авторизації) — може переглядати міста, райони, проєкти, інфраструктуру, карту та аналітику.
- **Архітектор** — може створювати та редагувати свої проєкти, додавати інфраструктуру до своїх проєктів, переглядати та редагувати власний профіль.
- **Адміністратор** — має повний доступ, включаючи управління користувачами, містами, районами та редагування будь-яких проєктів.

## Особливості реалізації

- Повністю адаптивний дизайн (Mobile First).
- Сучасний UI з анімаціями переходів між сторінками.
- Інтерактивна карта з відображенням міст, районів, проєктів та об'єктів інфраструктури.
